Modelo de documento não precificado

Use estas quatro colunas, nesta ordem, para o documento sem preço. Os dados abaixo são apenas exemplos: substitua-os pelos seus itens.

  1. Preencha o Excel: substitua todos os exemplos. Um item por linha; a quantidade já na unidade indicada. Medidas na descrição não convertem a quantidade.
  2. Código: pode ser o código do cliente ou o código Krona. Se não souber o código, deixe a célula vazia: o item é procurado pela descrição. Não numere as linhas (1, 2, 3…) na coluna do código.
  3. Preço: não é preciso preencher. Se o documento trouxer o preço de outro fornecedor, ele fica visível na comparação apenas como informação — o preço que conta é o da tabela do cliente.
  4. Exporte em PDF: mantenha as quatro colunas na mesma página. Confira que nenhuma descrição ficou cortada. Não acrescente títulos, logótipos ou notas fora da tabela; não envie uma imagem digitalizada.

Pedidos e orçamentos recebidos (Sienge, UAU, MRV, Terral…) também são aceites sem qualquer conversão: o sistema reconhece o layout. Este modelo serve para listas próprias.
